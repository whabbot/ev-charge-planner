# Track each build-plan milestone as a ticket in docs/tickets

Each of the five build-plan milestones has a ticket file in `docs/tickets/`. The ticket gives the milestone's scope, acceptance criteria, verification and the docs it must update. The build plan still takes precedence, and tickets carry their own `status`, so there is no separate tracker to keep in step. The re-plan job, which the build plan leaves unassigned, is placed in milestone 4.
